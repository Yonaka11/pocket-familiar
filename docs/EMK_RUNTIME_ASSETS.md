# EMK runtime asset status

Emi, Kaelani, and Mira are now registered as selectable Pocket Familiar runtime characters.

Each character currently uses:

- a daytime humanoid/chibi image for the collection avatar
- a nighttime spirit-animal image as the overlay prototype artwork
- the existing per-character preference, progression, touch-play, and physics systems

The night artwork is intentionally used as a static animation fallback for all movement/reaction states until production sprite atlases are created. This keeps the characters testable in the app now without pretending a single illustration is a finished animation pack.

Seraphi Astrea remains the launcher mascot through the existing adaptive launcher foreground/background resources.
