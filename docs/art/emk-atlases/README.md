# EMK Character Atlas References

These are compact repository previews of the current Pocket Familiar pixel-art character atlas direction for Emi, Kaelani, and Mira.

- `emi-character-atlas-preview.png`
- `kaelani-character-atlas-preview.png`
- `mira-character-atlas-preview.png`

These boards are visual design references only. They include labels, effects, and showcase layout, so they are not runtime overlay sprite atlases. Runtime assets should remain transparent, atlas-backed, and sized for the overlay renderer.

The full-resolution source boards are kept outside this repository preview set. Replace these previews with lossless source PNGs or final production transparent sprite sheets when the runtime atlases are cut and exported.
